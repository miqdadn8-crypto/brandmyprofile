# Prospect Scoring

Score every prospect before contacting. Do **not** invent DA/DR values; add them only from a real tool later.

| Factor | Range | Guide |
|---|---|---|
| Relevance | 0-3 | 3 = audience is GCC/Kuwait/India job seekers; 2 = general careers with GCC content; 1 = tangential; 0 = unrelated |
| Audience fit | 0-3 | 3 = readers would actually use a CV checklist/guide; 0 = no overlap |
| Editorial quality | 0-2 | 2 = genuinely written/curated and active; 1 = thin but real; 0 = autogenerated/dead |
| Link opportunity | 0-2 | 2 = clear resource list/article where a link fits naturally; 1 = possible; 0 = forced |

**Total 0-10:** 8-10 = high (contact first) | 5-7 = medium (contact if time) | 0-4 = low (skip).

Hard stops (do not contact): paid-link sites, PBNs, link farms, article-submission farms, random SEO directories, casino/crypto/adult/pharma neighbours, mandatory reciprocal links.

Record the score in `authority_relevance` of [prospect-tracker.csv](./prospect-tracker.csv), e.g. `9 (3/3/2/1)`.
Status vocabulary (kept from the earlier template): Researching, Qualified, Ready to Contact, Contacted, Follow-up 1, Follow-up 2, Replied, Accepted, Declined, Link Live, Not Suitable.
