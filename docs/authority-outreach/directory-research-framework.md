## Eligibility rules (apply to every directory before submitting)

- Only truthful information is submitted - no fake physical address, no fake founding date, no
  fabricated review count.
- The directory must have genuine editorial or community purpose - not a pure link-farm.
- Skip any directory that requires a physical street address BrandMyProfile doesn't have (it's an
  online, service-area business - see NAP rule below).
- Nothing is submitted automatically or in bulk - each listing is a deliberate, individually
  reviewed decision.
