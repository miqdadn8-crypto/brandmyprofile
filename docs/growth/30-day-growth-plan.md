# 30-Day Growth Plan (Kuwait > GCC > India)

Process targets, not outcome promises. Detailed outreach weeks: [../authority-outreach/2026-30-day-plan.md](../authority-outreach/2026-30-day-plan.md). Nothing here has been executed.

## Weekly rhythm (about 6-7 hours total)
| Day | Task |
|---|---|
| Mon | Search Console review (30 min) -> `gsc-opportunity-tracker.csv`; update `kpi-dashboard.md` |
| Tue-Thu | Prospect research + personalized outreach (see outreach plan); 3 GBP posts across the week |
| Fri | Follow-ups (max 2 per prospect); LinkedIn + Instagram posts (2 each/week); log all leads in `lead-tracker.csv` |
| After each completed job | Send one genuine review request |

## 30-day targets
20-30 prospects researched | 5-15 personalized emails/week | max 2 follow-ups | 2-3 GBP posts/week | 2 LinkedIn + 2 Instagram posts/week | 1 GSC review/week | every enquiry tracked. **No** ranking, lead-count or backlink-count guarantees.

## SEO opportunity rules (Search Console)
- **High:** commercial query, 50+ impressions, position 5-20, CTR below expected -> improve the existing page (title/description/hero/internal links).
- **Medium:** 10-49 impressions, position 5-30 -> monitor; improve if intent is strong.
- **Low:** irrelevant, low intent, job/employer queries (e.g. a company name + "HR") -> do not optimize.

### Decision rule: do not create a page for one query
Before any new page ask: is the intent already served? does an existing page rank for it? is it commercially valuable? would a new page cannibalize an existing one? Prefer improving existing pages. Never create pages for employer/job-title queries (the sample Jobs section is deliberately noindex).
