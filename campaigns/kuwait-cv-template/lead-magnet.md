# Kuwait CV Template Pack

**Page:** /resources/kuwait-cv-template (src/pages/KuwaitCvTemplate.tsx), no email gate, same pattern as /resources/gcc-cv-checklist.
**Files:** public/resources/kuwait-cv-template/kuwait-cv-template-{general,fresher,nurse,driver}.docx and kuwait-cv-example-{…}.pdf
**Regenerate:** edit source/templates.cjs, then from a folder with `docx@9.0.2` and `playwright@1.49.1` installed: `node source/build.cjs public/resources/kuwait-cv-template`.

## What's in each template
| Role | Section order | Role-specific guidance |
|---|---|---|
| General | Contact + target role → Summary → Key Skills → Work Experience → Education → Certifications & Licences → Languages | Skills named exactly as in the advert; results, not duties |
| Fresher | Contact → Summary → **Education first** → Internships & Projects → Skills → Training → Languages → Activities | One page; "what came of it", not "participated in" |
| Nurse / healthcare | Contact → Summary → **Licence & Registration** → Clinical Experience → Certifications (BLS/ACLS + expiry) → Education → Languages | Unit, capacity, patient load; "check current Ministry of Health requirements" (no MOH specifics stated) |
| Driver | Contact → Profile → **Driving Licence** (type, vehicles, expiry) → Work Experience → Training → Languages | Vehicle types, Kuwait areas covered, safety record only if true |

Every Word template opens with a shaded guidance box (delete before sending) that names BrandMyProfile and the free review. The CV itself carries no BrandMyProfile branding, because job seekers send it to employers.
